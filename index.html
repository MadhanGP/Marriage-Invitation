How to Add Your Own Music & Deploy

Step 1: Adding Your Audio File

Name your audio file music.mp3 and place it in the same folder as this index.html file in your repository.

Line 64 of this file is already linked to music.mp3. If you prefer another name or path, change line 64:
<source src="your-song-name.mp3" type="audio/mpeg">

Step 2: Fallback Audio Engine

If you do not upload an MP3 file, you don't need to worry! The website automatically detects the missing file and gracefully switches to a built-in romantic D-Major piano & warm strings synthesizer using Web Audio API.

Step 3: Deploying to GitHub Pages in 2 Minutes

  1. Create a new repository on GitHub (e.g., madhan-dhivya-wedding).
  2. Upload this index.html and your music.mp3 into the repository root.
  3. Go to Settings → Pages.
  4. Under Branch, choose main (or master) and click Save.
  5. Your site will be live at: https://<your-username>.github.io/<repo-name>/
